## How I put a transaction together

<img src="https://raw.githubusercontent.com/Moinulhasan/Moinulhasan/main/assets/architecture.svg" alt="Request path from clients through Nginx and Laravel into queues, cache and the ledger" width="100%">

The shape is the same whether it's a metro fare, a cinema seat, or a distributor's monthly commission. Take the payment synchronously and write it once. Push receipts, notifications and reconciliation onto a queue. Cache the reads. Lock the balance. Assume the gateway will call you back twice.
